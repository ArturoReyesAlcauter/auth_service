5. Verificar que el proyecto lea la base correcta
Ejecuta:
uv run python -c "from app.core.config import settings; print(settings.DATABASE_URL)"


6. Aplicar migraciones pendientes
Después de un git pull, normalmente debes ejecutar:
uv run aerich upgrade

7. Ejecutar seed
Después de tener la base con tablas, ejecuta:
uv run python seed.py

9. Levantar el proyecto
Usa este comando recomendado:
uv run python -m uvicorn app.main:app --reload --port 8001

Si no hay bloqueo, también puede funcionar:
uv run uvicorn app.main:app --reload --port 8001
